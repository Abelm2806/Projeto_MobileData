# Mobile Data Store

Sistema de Gestão Inteligente para Loja de Telemóveis desenvolvido em **Python**. O projeto apresenta uma arquitetura modular e oferece duas formas de interação: uma interface de linha de comandos interativa (**CLI** com menus navegáveis por setas) e um _dashboard_ web moderno (**Streamlit**).

---

## Ferramentas

- **Linguagem:** Python 3
- **Base de Dados:** SQLite (`sqlite3`)
- **Interface Web:** Streamlit (`app.py`)
- **Interface CLI:** Questionary (`main.py`)
- **Manipulação de Dados:** Pandas
- **Gráficos e Estatística:** Matplotlib

---

## Funcionalidades

- **Gestão de Inventário (CRUD):** Controlo completo e integrado de Telemóveis, Clientes e Fornecedores.
- **Registo de Vendas:** Associação de clientes a produtos com atualização automática de stock em tempo real.
- **Análise de Dados e Gráficos:** Visualização estatística e relatórios de desempenho.
- **Exportação:** Capacidade de descarregar dados estruturados diretamente para formato **JSON**.
- **Área de Testes:** Inicialização automática de dados de exemplo e suporte a rotinas de manutenção.
